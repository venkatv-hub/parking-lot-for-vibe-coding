# Changelog

## 0.1.0 (first release)

- Shared Markdown backlog at `.ideas/backlog.md`.
- Claude Code / Codex plugin: `idea:` prompt hook (keeps ideas out of context), `ideas`, `idea go N`, `idea triage`.
- MCP server with `park_idea`, `list_ideas`, `get_idea`, `update_idea`.
- `idea` command-line tool for any terminal agent.
- VS Code extension (also Cursor, Windsurf, Kiro): sidebar with a + button, click an idea to send it to Claude Code, Codex, Copilot Chat, the terminal or the clipboard.
